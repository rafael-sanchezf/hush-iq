## What is hackathon work (built Oct 26 to Nov 4)

Everything after the import commit. The commit history of this repository is the record; the pieces, in
the order they land:

1. **Hosted API.** The FastAPI service deployed as a public endpoint (first on Vercel, Oct 26 night), open
   CORS, cache in `/tmp`, a prefix shim. Commit "Hosted API".
2. **Listing reader agent** (`services/agent/`). A listing URL, pasted text or photos go to a Meta model
   (Muse Spark through the Meta Model API, multimodal); it extracts the address, floor and exposure, quotes
   the span of the listing each came from, asks only for what it could not read, then geocodes and scores.
   A `submit_listing` tool refuses a result whose fields have no quoted span. Each turn is shown.
3. **Bounded AI adjustments.** The model reads what the math cannot: 311 complaint descriptions at the
   building (the same line, every weekend, is a neighbour), DOB permit descriptions (a facade job is months,
   a new building is years), each licensed venue's name and listing for closing time, listing cues about
   the floor and the side. It emits structured adjustments, capped per ingredient, each citing the rows it
   used; a `submit_adjustment` tool refuses any adjustment whose cited rows are not in the pull or whose
   size exceeds the cap. The UI shows base, adjusted and why.
4. **Grounded verdict writer.** The "what you'll hear" paragraph for this renter, generated by Muse Spark
   Open (served on Baseten), constrained to a JSON schema whose citations are an enum of the evidence lines
   sent, validated server-side, template fallback.
5. **Voice intake.** Muse Voice Transcribe turns "light sleeper, sirens kill me, fourth floor facing the
   street" into the profile and unit fields.
6. **Compare**, two or three listings for the same renter with the trade-off written by piece 4.
7. **Website** (`apps/web/`): live demo, API docs, the page for listing sites, the method page.
8. **An eval** of 20 cases that checks every citation points at a real row, run on every change.

The demo video shows only pieces 1 to 8. The model's prior existence is said out loud in its first ten
seconds.
